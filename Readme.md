# Advanced Web Technology - Practical Programs

This repository contains the practical programs performed for the
Advanced Web Technology laboratory.

The experiments cover HTML5, CSS3, JavaScript, jQuery, React.js,
Node.js, Express.js and MongoDB.

---

|-----|---------------------------------------------------|
| No. |                       Practical                   |
|-----|---------------------------------------------------|
| 01  | Design your Professional CV using HTML5 and CSS3  |
| 02  | Design a Registration Form using HTML5 and CSS3   |
| 03  | Design a Login Form and Validate using JavaScript |
| 04  | Build a Password Strength Indicator using jQuery  |
| 05  | Create a Star Rating System using jQuery          |
| 06  | Design a Basic Homepage using React.js            |
| 07  | Create a Simple Login Form using React.js         |
| 08  | Connect React.js with MongoDB                     |
