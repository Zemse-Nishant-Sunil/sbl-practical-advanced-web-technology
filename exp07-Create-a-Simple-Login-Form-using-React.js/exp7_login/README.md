⚛️ Experiments 06 
These experiments use React.js.
Prerequisites

Install Node.js:
https://nodejs.org/

Check the installation:
node -v
npm -v

Go to the respective experiment folder:

cd exp07-Create-a-Simple-Login-Form-using-React.js

Install dependencies:
npm install

Start the application:
npm start

The application will normally run at:
http://localhost:3000
